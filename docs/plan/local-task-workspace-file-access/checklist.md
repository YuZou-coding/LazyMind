- [ ] Local 和 Desktop 的 Work 任务可选择本地工作区。（待人工 E2E）

- [x] Office、其他业务模块和外部依赖与 `origin/main` 一致。

## 工作区选择与授权

- [x] 新 Work 默认显示“选择工作区”，不默认选中任何目录。
- [x] 点击工作区入口可展开或收起菜单。
- [x] 工作区按名称和路径实时搜索。
- [x] 点击有效授权直接切换并关闭菜单。
- [x] 点击失效授权弹出“首次使用时需要授权”。
- [x] 授权框显示目录名称、路径及仅限该目录和子目录的范围。
- [x] 授权框取消、关闭、遮罩和 `Esc` 均不授权、不切换。
- [x] 点击“允许访问”后授权并切换。
- [x] “打开本地文件夹”调用系统原生目录选择器。
- [x] 原生选择器取消时保持当前工作区。
- [x] “不使用本地工作区”清除选择并禁用权限入口。
- [x] 一个 Work 任务最多绑定一个工作区；已有任务不能换绑。
- [x] 工作区选择不修改 file-watcher、知识库或其他文件授权。

## 授权管理与撤销

- [x] 用户可查看当前和最近授权工作区。
- [x] 用户可撤销授权并看到受影响任务数量。
- [x] 撤销后主任务、子 Agent、Skill 和尚未提交的文件操作不能继续访问。
- [x] 同一路径重新授权产生新授权，不恢复旧任务。
- [x] 目录移动、删除或同路径重建后原授权失效。

## 文件能力与边界

- [x] 授权范围内可以列出、搜索和读取文件。
- [x] 授权范围内可以创建目录和文件。
- [x] 授权范围内可以覆盖、追加和精确修改文件。
- [x] 文件 API 不暴露删除、移动、重命名、链接、权限或所有权修改。
- [x] 公开输入只接受工作区相对路径。
- [x] 绝对路径、`..`、空字节、驱动器/UNC 越界被拒绝。
- [x] 符号链接和父目录替换不能逃逸工作区。
- [x] 文件修改使用版本校验和同目录原子提交。
- [x] 操作前和提交前重新验证用户、任务、绑定、授权和目录身份。
- [x] 越界、撤销和目录身份变化返回稳定且不泄露主机路径的错误。
- [x] 主 Agent、子 Agent 和 Skill 不能扩大任务授权范围。

## 三档权限

- [x] 权限保存在 Work 任务与工作区绑定上。
- [x] 新任务默认 `ask_as_needed`（按需确认）。
- [x] 未选择工作区时权限入口不可用。
- [x] 权限菜单包含“始终询问 / 按需确认 / 全部允许”。
- [x] `always_ask` 对文件编辑、联网和已连接应用副作用询问。
- [x] `ask_as_needed` 仅对项目已有风险识别命中的操作询问。
- [x] `allow_all` 必须先展示风险确认框。
- [x] 风险框展示文件和文件夹、命令和系统操作、互联网和已连接应用风险。
- [x] 风险框取消、关闭、遮罩和 `Esc` 保持原权限。
- [x] 点击“确认开启”后才切换为 `allow_all`。
- [x] `allow_all` 不能绕过越界、撤销、提权、系统破坏和永久禁止项。
- [x] 权限切换不自动批准切换前已经 pending 的操作。
- [x] 一次性批准复用现有工具批准链，不新增复杂长期持久化或资源队列。
- [x] 一次性批准、命令适配和已连接应用权限均由 LazyMind 后端实现，不修改 LazyLLM。
