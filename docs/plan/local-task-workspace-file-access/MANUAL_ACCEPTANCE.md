# Local/Desktop Work 本地工作区人工验收

更新时间：2026-09-04

## 准备目录

创建一个仅用于验收的目录，放入 `source.txt`，内容为 `before target after`。在该目录
旁边另建一个不授权目录并放入 `secret.txt`，用于验证越界阻止。不要选择包含真实凭据
或重要文件的目录。

## Local

1. 运行 `make local-up`，打开 `http://localhost:8090` 并进入新建 Work。
2. 确认默认显示“选择工作区”和“按需确认”，权限入口禁用。
3. 打开工作区菜单，验证名称/路径搜索、再次点击收起、点击空白和 Escape 关闭。
4. 点击“打开本地文件夹”，先取消系统选择器，确认状态不变；再次打开并选择验收目录。
5. 在 LazyMind 授权框分别验证关闭、遮罩、Escape 和取消均不授权；最后点击“允许访问”。
6. 确认工作区切换成功、权限入口启用，创建 Work 并让 Agent：读取 `source.txt`；创建
   `generated/new.txt`；把 `source.txt` 中 `target` 精确替换为 `replacement`；追加一行。
7. 要求读取 `../secret.txt`，确认操作被拒绝，并显示明确的工作区权限阻止提示且不泄露
   邻接目录的完整主机路径或内容。
8. 依次检查始终询问、按需确认和全部允许。全部允许必须先显示文件、命令、互联网、
   连接应用四类风险；取消/关闭/遮罩/Escape 不生效，确认后才生效。
9. 在任务运行或准备写入时撤销授权，确认后续读写和提交失败；同路径重新授权后，旧任务
   仍不可访问，新 Work 可以绑定新授权。
10. 进入 Chat，确认没有工作区入口，也不能通过请求获得本地文件能力。

## Desktop

使用当前平台打包应用重复 Local 的 2 至 10 步，额外确认目录选择器是系统原生窗口，
renderer 没有可输入任意路径的界面，应用重启后最近工作区与失效状态显示正确。

## 视觉与无障碍

- 中英文切换后文案完整，无截断或重叠。
- Tab 能到达工作区按钮、搜索框、菜单项和弹窗按钮；焦点样式可见。
- Escape、关闭按钮和遮罩行为一致；工作区菜单和权限菜单不会同时展开。
- 控件顺序、弹窗结构和主要尺寸与产品图例一致。
