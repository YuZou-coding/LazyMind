# Local/Desktop 任务工作区（第一迭代）验收清单

## 阶段二实现核对（2026-09-01）

- 自动化已覆盖并通过：模式门禁、可信宿主登记、一次性候选 token、授权/复用/撤销、任务原子绑定、所有权、并发与失效状态、路径身份变化、第一迭代文件能力关闭、Local/Desktop 桥接边界、图片对应的前端结构与交互契约。
- 数据与契约已核对：SQLite 文件数据库路径、PostgreSQL/SQLite migration 建库/升级/回退、Core OpenAPI、生成客户端和稳定错误目录保持一致。
- Local 最终代码已通过 `make local-up` 重建并启动，Local Proxy、Core 与前端健康检查通过。
- 待人工验收项保持未完成：真实 macOS 系统选择器操作、真实 Desktop 界面闭环，以及带已配置模型的完整“选择—授权—创建任务—重启—复用—撤销”业务流程。
- 下列逐项清单仍作为最终人工验收记录使用；自动化通过不替代需要真实系统界面或业务环境的人工勾选。

## 范围和模式

- [ ] `new_task` 明确映射为 Work；`quick_question` 明确映射为 Chat。
- [ ] Local（`make local-up`）和 Desktop 的 Work 模式显示工作区入口。
- [ ] Chat、Cloud 和 `make local-up-lan` 不显示入口，直接构造请求也返回 `LOCAL_WORKSPACE_MODE_FORBIDDEN`。
- [ ] 第一迭代没有文件读取、创建、修改、删除、搜索或命令执行能力；相关调用返回 `LOCAL_FILE_ACCESS_NOT_ENABLED`。

## UI 与图片一致性

- [ ] 控件顺序为“添加 → 选择工作区 → 确认方式 → 思考深度”，与样例图一致。
- [ ] 未选择控件包含文件夹图标、“选择工作区”和下拉箭头。
- [ ] 展开面板包含搜索框、最近工作区名称/路径、分隔线、“打开本地文件夹”和“不使用本地工作区”。
- [ ] 面板宽度、圆角、阴影、间距、字体层级、列表行高和控件高度经截图或人工 Review 与样例图核对。
- [ ] 最近工作区默认最多 8 条，按 `last_used_at` 倒序；搜索只过滤授权记录，不扫描磁盘。
- [ ] 最近行默认外观与样例一致；悬停或键盘聚焦时才显示管理操作，且不改变行高或菜单布局。
- [ ] 管理操作可查看完整范围和撤销；撤销确认显示路径及受影响任务数量。
- [ ] 键盘可打开面板、搜索、选择工作区和关闭面板，焦点状态可见。
- [ ] 中文和英文文案均存在，长路径不会破坏布局且可查看完整值。
- [ ] 已有 Work 任务显示只读的绑定名称和状态，可查看范围或撤销；无绑定的旧任务不能补绑；Chat 会话仍不显示控件。
- [ ] 首次授权弹窗与新增第一张图片一致：标题、副标题、关闭按钮、目录卡片、完整路径、范围说明、底部分隔线、“取消”和“允许访问”均存在且顺序一致。
- [ ] 点击关闭或“取消”不创建授权、不选择工作区；点击“允许访问”成功后才创建授权并选中。
- [ ] 已有效授权的最近工作区不重复弹窗；撤销、目录身份变化或重新授权时再次弹窗。

## 原生选择与授权

- [ ] Desktop 通过 Electron main process 调起目录选择器，renderer 不直接访问 Node 文件系统。
- [ ] Local 通过 loopback-only 本机接口调起系统目录选择器，不依赖浏览器返回绝对路径。
- [ ] 点击“打开本地文件夹”触发 macOS 原生系统目录选择器，不由前端仿制；实际操作选择原地目录，目录内容不会被读取或上传，系统文案和外观允许随 macOS 版本变化。
- [ ] Local 接口拒绝 LAN、非 loopback、非允许 Origin 和无有效本机会话请求，错误为 `LOCAL_WORKSPACE_SELECTION_FORBIDDEN`。
- [ ] Local 选择/登记请求具有 CSRF 或一次性请求凭据保护；其他本地网页不能触发授权。
- [ ] 用户取消选择不创建工作区、不改变当前待选状态，返回可观察的 `canceled` 结果而非错误。
- [ ] 系统选择后只创建单次候选 token；token 5 分钟过期、使用一次后失效，并绑定当前本机会话。
- [ ] 相对路径、不存在路径、文件路径、不可访问路径和真实路径解析失败返回 `LOCAL_WORKSPACE_PATH_INVALID`。
- [ ] 可用时记录平台目录身份指纹；同一路径被删除后重建或替换不会自动继承旧授权。
- [ ] LazyMind 首次授权弹窗显示将授权的完整真实目录路径和“仅该文件夹及其子目录”范围。
- [ ] 前端和 renderer 可读取名称、路径和状态用于授权范围展示，但变更请求只提交不透明 `workspace_id`，不能用任意路径字符串创建授权。
- [ ] 授权记录只保存在当前 Local/Desktop 实例，不上传或跨设备同步。
- [ ] 授权记录不包含目录内容、文件清单、摘要或 Secret；保存读取 `allow`、修改 `ask_before_write` 策略，但第一迭代文件工具仍关闭。
- [ ] 工作区选择不改变 Desktop `local-folder-access.json`、file-watcher `allowedRoots` 或知识库扫描权限。

## 任务绑定

- [ ] 一个 Work 任务最多绑定一个工作区，数据库具有唯一约束。
- [ ] 从最近列表选择有效工作区可供新任务复用，不重复打开系统选择器。
- [ ] 工作区与首条消息创建的任务/会话原子绑定；任一步骤失败都不留下半绑定任务。
- [ ] 服务端根据可信运行配置和 `run_in_background`/持久化任务类型共同判定 Work，不信任前端显示状态。
- [ ] 首条消息发送后不能切换或移除绑定，返回 `LOCAL_WORKSPACE_BINDING_LOCKED`。
- [ ] 并发绑定不同工作区只有一个成功，失败方返回 `LOCAL_WORKSPACE_BINDING_CONFLICT`。
- [ ] 其他用户或任务不能读取、绑定或撤销不属于自己的记录，统一安全失败。
- [ ] 无工作区的新任务仍可正常创建，状态为 `none`。
- [ ] 首条消息后无论绑定为 `active`、`revoked`、`path_unavailable` 或 `none`，均不能切换、移除或补绑。
- [ ] 待选工作区在发送前被其他窗口撤销时，创建失败、不留下绑定，并保留用户输入供重新选择。

## 撤销与重新授权

- [ ] 撤销前确认界面展示完整路径和受影响任务数量。
- [ ] 撤销授权在事务中完成；全部相关任务通过授权状态即时派生为失效，不依赖异步逐条更新。
- [ ] 撤销后相关任务状态立即为 `revoked`，内部工作区解析返回 `LOCAL_WORKSPACE_REVOKED`。
- [ ] 撤销不删除历史对话，历史任务仍可查看。
- [ ] 重新授权同一路径产生新的有效授权身份，旧任务不会自动恢复；新任务可以绑定。
- [ ] 归档任务仍计入撤销影响范围；永久清除任务同步清除其绑定。
- [ ] 不存在或不属于当前本机用户的 ID 返回 `LOCAL_WORKSPACE_NOT_FOUND`，不泄露其他记录。

## 路径与第二迭代预留

- [ ] 授权和解析均使用规范化真实绝对路径。
- [ ] 每个任务绑定用户精确选择的根目录；第二迭代仅允许该根及其后代，不允许父目录或兄弟目录。
- [ ] 已授权父目录后再选择子目录，任务仍绑定精确子目录，不被静默扩大为父目录。
- [ ] `..`、符号链接和授权后目录替换不能扩大授权范围。
- [ ] `path_unavailable` 不因路径字符串再次存在而自动恢复，重新使用必须产生新的显式授权身份。
- [ ] 内部解析统一验证部署模式、Work 类型、任务所有权、唯一绑定、授权状态和真实路径。
- [ ] 第一迭代不会把授权真实路径注入模型提示、聊天消息或 Agent 文件工具。
- [ ] 第二迭代继续使用统一解析边界，不新增平行授权体系；最终策略以 `docs/plan/local-task-workspace-file-access/` 为准。
- [ ] 第一迭代的 `ask_before_write` 仅是未发布预留值；第二迭代通过双数据库迁移改为允许的创建/修改 `allow`；Agent 直接删除、移动和重命名永久禁止，受控程序范围内副作用以第二迭代规格为准。

## 数据库、契约与恢复

- [ ] API 契约、实现、前端类型、稳定错误目录和测试一致。
- [ ] Local/Desktop SQLite 文件数据库完成建库、升级、重启恢复和事务验证，不以内存 SQLite 代替。
- [ ] 如新增 Core migration，同时提供 up/down，并验证 PostgreSQL 与 SQLite 升级、回退、数据保留和唯一约束。
- [ ] Cloud/Docker Compose 路由保持禁用或行为不变，相关回归通过。
- [ ] 服务器模式门禁来源于受控运行配置，不因伪造 `VITE_LAZYMIND_MODE` 或请求字段而开放。
- [ ] 授权状态文件或数据库记录损坏、缺失、不可读时安全失败为无有效授权。
- [ ] 普通日志、指标和对外错误不包含完整本地路径；仅授权管理界面在用户主动操作时展示。

## 端到端

- [ ] Local：打开 Work → 选择目录 → 明确授权 → 创建任务 → 重启 → 绑定仍有效。
- [ ] Desktop：完成相同闭环并验证 Electron IPC 边界。
- [ ] 两个任务复用同一授权后撤销，该两个任务均立即失效。
- [ ] 恶意 renderer、本地第三方网页和直接构造路径请求均不能创建授权。
- [ ] Chat 模式无法通过 UI 或直接请求获得工作区绑定。
- [ ] 用户提供的五张图片作为视觉 Review 基准；第二张新增图片按 macOS 原生系统选择器行为验收，其余 LazyMind 自有工作区控件和授权弹窗按图片核对。
- [ ] 所有未运行的跨平台或环境验证均在阶段报告中明确披露。
